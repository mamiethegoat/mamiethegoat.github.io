# Runner.co.za

## South Africa's Running Community Platform

Runner.co.za is a digital community and content platform built specifically for South Africa's running community.

The platform connects **runners, running clubs, athletes, coaches, influencers, content creators, and race organisers** in one central destination.

Users can discover races, read running content, share their experiences, find clubs, view race results, access training advice, and connect with other runners.

### Core Value

> **Discover. Participate. Share. Grow.**

Runner.co.za aims to become the **online home of South African running**.

---

# 1. Product Overview

Runner.co.za combines several experiences into one platform:

* Running community
* Digital running magazine
* Race discovery platform
* Race results database
* Running club directory
* Training and advice hub

* Newsletter and subscription platform

The platform should feel like a modern sports media and community product rather than a traditional blog.

# 33. Security

Security should be treated as a core requirement.

Implement:

* Secure authentication
* Password hashing through the authentication provider
* Role-based permissions
* Database row-level security
* Input validation
* File upload validation
* Rate limiting where appropriate
* Protection against spam
* Secure API endpoints

Never expose:

* Passwords
* Authentication tokens
* Private user information
* Admin credentials
* API secrets

Secrets must be stored using environment variables.

---

# 34. Environment Variables

Use environment variables for external services.

Example:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

Never commit secrets to Git.

Provide an `.env.example` file.

* What races are happening near me?
* What happened at the latest race?
* Where can I find a running club?
* How should I train for my next race?
* What are other runners talking about?

The ultimate goal is to create a strong, active running ecosystem where people return regularly because Runner.co.za is where they **discover races, learn, connect, participate and share their running journey.**
